# LED Плёнка - Сайт для гибкого светодиодного экрана

Современный одностраничный сайт для продвижения LED-плёнки с админ-панелью для управления заказами.

## 🚀 Деплой на Railway

### Предварительные требования
- Аккаунт на [Railway](https://railway.app)
- Git репозиторий с кодом

### Инструкция по деплою

1. **Подготовка проекта:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   ```

2. **Деплой на Railway:**
   - Перейдите на [railway.app](https://railway.app)
   - Нажмите "New Project"
   - Выберите "Deploy from GitHub repo"
   - Подключите ваш репозиторий
   - Railway автоматически определит Node.js проект и запустит его

3. **Настройка PostgreSQL:**
   - Добавьте PostgreSQL сервис в Railway
   - Railway автоматически создаст переменную `DATABASE_URL`
   - Сервер автоматически создаст таблицы при первом запуске

4. **Переменные окружения (опционально):**
   В настройках проекта Railway можно добавить:
   ```
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=your_secure_password
   ```

5. **Автоматический деплой:**
   Railway автоматически деплоит при каждом push в репозиторий

## 🔧 Локальная разработка

### Установка зависимостей:
```bash
npm install
```

### Запуск сервера:
```bash
npm start
```

Сайт будет доступен по адресу: `http://localhost:3000`

### Режим разработки (с автоперезагрузкой):
```bash
npm run dev
```
(Требуется установка nodemon: `npm install -g nodemon`)

## 🌐 API Endpoints

### Заказы
- `GET /api/orders` - Получить все заказы
- `GET /api/orders/:id` - Получить заказ по ID
- `POST /api/orders` - Создать новый заказ
- `PATCH /api/orders/:id` - Обновить статус заказа
- `DELETE /api/orders/:id` - Удалить заказ

### Статистика
- `GET /api/stats` - Получить статистику заказов

### Админка
- `POST /api/admin/login` - Авторизация админа

## 🔐 Админ-панель

**Доступ:** `/admin.html`

**Демо-учетные данные:**
- Логин: `admin`
- Пароль: `admin123`

⚠️ В production измените пароль через переменные окружения!

## 💾 Хранение данных

Заказы хранятся в PostgreSQL базе данных на Railway. База данных автоматически инициализируется при первом запуске сервера.
